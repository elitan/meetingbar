# MeetingBar 1.6.0

Optional automatic cleanup of old meetings.

- Configure automatic deletion in **Settings → General → Storage**, with a default limit of 30 days and a supported range of 1–3,650 days.
- Applies retroactively after confirmation: expired meetings lose their transcript, library entry, and all local source and playback audio, including pinned and failed meetings.
- Disabled by default. Cleanup runs on launch and hourly while the app is open; active recordings and transcriptions finish first.
- Deleted queued meetings are skipped before transcription starts.
- General now appears first in the settings sidebar.

Exported copies, backups, models, settings, and cloud-provider records are not removed by this setting. This is not a secure-erasure guarantee.

## Validation

122 tests passed, 5 optional tests skipped, zero failures. Tests cover retention boundaries, persisted preferences, full meeting-file deletion, protected active work, deleted transcription jobs, and settings ordering. The arm64 Release build passed. Native UI verification confirmed the retention controls and destructive confirmation; automatic deletion was left disabled on the installed app.
