# MeetingBar 1.5.2

Clear feedback when copying a transcript.

- The Copy button shows a green checkmark and **Copied** for two seconds after a successful clipboard write.
- Clicking again restarts the timer; switching meetings clears the feedback.
- Button space stays reserved so the surrounding controls do not move.
- A failed clipboard write shows **Copy failed**, with a retry hint, instead of claiming success.
- Accessibility labels describe the current copy result.

## Validation

117 tests passed, 5 opt-in real-model tests skipped, zero failures. An isolated clipboard test verifies exact transcript copying, including Swedish characters and speaker formatting, and replacement of earlier clipboard contents. The arm64 Release build passed. Native computer-use verification confirmed the green Copied state and its return to Copy without moving neighboring controls.

## Distribution

Requires Apple Silicon and macOS 26 or later. This is a source release, with no notarized app download attached. Recording, transcription, and audio retention behavior are unchanged.
