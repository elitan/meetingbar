# MeetingBar 1.7.0

Faster ways to find, review, and reopen meetings.

- **Keyboard navigation in the library.** ↑/↓ move between meetings, Delete asks to delete the selected meeting, Space plays or pauses its audio, and ⌘F jumps to search. From search, ↓ or Return moves into the list.
- **Date groups.** Meetings are grouped into Pinned, Today, Yesterday, Previous 7 Days, Previous 30 Days, and older months.
- **Search shows why a meeting matched.** Results include the matching transcript excerpt, and the open transcript highlights every match and scrolls to the first.
- **Playback controls.** Skip back or forward 15 seconds, and listen at 1×, 1.25×, 1.5×, or 2×. The speed is kept while switching meetings.
- **Recent meetings in the menu bar.** The popover lists the last three meetings, shows when one is still transcribing, and opens any of them in the library.
- **Clearer labels.** Dates read "Today, 10:30" and list durations "32 min". The recording card and the sidebar's New Recording button show the global shortcut. The popover's duplicate Settings button is gone.

The test host now uses an in-memory library and a temporary file store, so running the tests never opens a real or shared SwiftData store.

## Validation

134 tests passed, 5 optional tests skipped, zero failures. New tests cover date grouping, relative dates, compact durations, search excerpts and highlighting, and playback speed. Rendered screenshots of the library, menu-bar popover, and search highlighting were reviewed with fictional meetings. The arm64 Release build passed and was installed locally with the stable ad-hoc signature.
