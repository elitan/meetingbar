# MeetingBar 1.5.1

Delete meetings directly from the library sidebar, without scrolling to the bottom of a transcript.

## Fixed

- Right-click a meeting and choose **Delete Meeting…**. The confirmation names the meeting you clicked, even when another meeting is selected.
- Confirming permanently removes that meeting's transcript and all local audio files, including microphone/system tracks and balanced playback audio. Cancelling leaves the meeting untouched.
- Sidebar and transcript deletion use the same confirmation and error handling. Playback of the selected meeting is stopped before its files are removed, and an active recording cannot be deleted.
- The README now explains right-click deletion.

## Validation

116 tests passed, 5 opt-in real-model tests skipped, zero failures. New isolated tests verify full audio/transcript deletion, preservation of other meetings, and deletion when source audio is already absent. The arm64 Release build passed.

The installed app was checked with native computer use: right-clicking an unselected meeting opened its context menu, the confirmation named that meeting rather than the selected one, and cancelling preserved both the meeting and the original selection. No personal recordings were deleted during verification.

## Distribution

Requires Apple Silicon and macOS 26 or later. This is a source release, with no notarized app download attached. Existing recordings, preferences, and credentials are unchanged unless you explicitly delete a meeting.
